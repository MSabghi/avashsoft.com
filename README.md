# وب‌سایت توسعه راهکار آوش - نسخه Next.js

این پوشه شامل کد کامل وب‌سایت آوش است. برای راه‌اندازی، راهنمای نصب ساده در فایل
`راهنمای-نصب-ساده-آوش.docx` یا `راهنمای-نصب-ساده-آوش.pdf` را مطالعه کنید.

## شروع سریع

```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. کپی فایل محیط
cp .env.example .env
# سپس فایل .env را ویرایش کنید و NEXTAUTH_SECRET را تنظیم کنید

# ۳. آماده‌سازی پایگاه داده
npm run db:push
npm run scripts/seed.ts

# ۴. اجرای سایت در حالت توسعه
npm run dev
```

سپس مرورگر را روی http://localhost:3000 باز کنید.
